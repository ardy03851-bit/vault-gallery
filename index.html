Security & backup

Local-only by design.

Your images are written to this browser's IndexedDB on this device. No server, no account, no analytics, no upload.

Optional vault encryption.

Set a passphrase and every image, thumbnail, caption and tag is encrypted with AES-256-GCM before it touches storage. The key is derived with PBKDF2 (600,000 iterations) and only ever exists in memory while the vault is unlocked.
